Architecture Reference Blueprint: Zero-Trust Automated Secret Rotation

Enterprise Standard

1. Core Architecture Principles

  • Phase 1: Transition to Cloud Managed Identities — Completely deprecate client secrets in favor of System-Assigned and User-Assigned Managed Identities or AWS IRSA / GCP Workload Identity Federation. Eliminates credentials from app configs entirely.
  • Phase 2: Event-Driven Lifecycle Triggers — When a certificate or secret reaches 30 days before expiration, dispatch an automated event notification to a serverless automation runbook.
  • Phase 3: Automated Certificate Authority Integration — Integrate Key Vault / Secrets Manager with certified CAs for automatic zero-downtime certificate renewal and deployment.

2. Infrastructure-as-Code Automation Recipe

keyvault-autorotation.bicep 
// Cloud Infrastructure: Automated Expiration Event Subscription
resource eventSubscription 'Microsoft.EventGrid/eventSubscriptions@2022-06-15' = {
  name: 'evsub-keyvault-nearexpiry'
  scope: keyVault
  properties: {
    destination: {
      endpointType: 'AzureFunction'
      properties: {
        resourceId: autoRotateFunction.id
        maxEventsPerBatch: 1
      }
    }
    filter: {
      includedEventTypes: [
        'Microsoft.KeyVault.SecretNearExpiry',
        'Microsoft.KeyVault.CertificateNearExpiry'
      ]
    }
  }
}
